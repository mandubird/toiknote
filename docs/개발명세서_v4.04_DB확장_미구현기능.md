## 1️⃣ users.score_range 컬럼

### 목적
사용자 레벨 구간을 **계산값이 아닌 DB 고정값**으로 관리 (프로그램 분기 / 가격 제안 / 통계 분석용).

### DB 변경
- `users` 테이블 컬럼 추가:
  - `score_range VARCHAR(20)` (또는 `TEXT`)
  - 허용 값: `600-700`, `700-800`, `800-900`, `900+`

### 저장 로직
- **진단 완료 시**: `score_range = getScoreRange(diagnostic_score)` 저장
- **재진단 시에만** 업데이트 (이후 일상 학습으로 변경 금지)

### 사용처
- `program_templates.target_range` 매칭
- 가격 제안 분기
- 대시보드 상단 표시

## 2️⃣ 점수 예측 로직 고도화 (Part7 시간 패널티)

### 목적
실전형 예측 점수 정확도 상승.

### DB 영향
- 없음 (기존 `score_prediction` 테이블 유지).

### 신규 계산 공식
```
예측점수 =
  (LC 정확도 × 5) + (RC 정확도 × 5)  → 0~990 스케일로 환산
  - Part7 시간 패널티
```

### Part7 시간 패널티
- 기준: 1문제 평균 **75초**
- `평균 ≤ 75초` → 패널티 **0**
- `76~90초` → **-10**
- `91~110초` → **-20**
- `111초 이상` → **-30**

### API 수정
- `calculateEstimatedScore()` 또는 점수 예측 파이프라인에서:
  - Part7 평균 시간: `fetchSegmentStats()` → `avgPart7TimeSeconds`
  - 위 패널티 적용 후 `score_prediction.predicted_score` 업데이트

### 노출 조건 (유지)
- Week4 이상
- Pro 사용자
- 최소 200문제 이상 (선택)

## 3️⃣ program_status completed 상태

### 목적
프로그램 **정상 종료** 구분.

### DB 변경
- `users.program_status` CHECK에 `'completed'` 추가.
- 기존: `'none' | 'active' | 'expired'` → 추가: `'completed'`.

### 상태 전이
- **week8 완료** → `program_status = 'completed'`
- **구독 만료** 등 → `program_status = 'expired'`

## 4️⃣ 결제 후에만 program active 허용

### 목적
무료 사용자의 **무제한 프로그램 진입 방지**.

### 로직 수정
- **현재**: 진단 완료 → Week1 시작 가능 (즉시 `program_status = active`).
- **수정**:
  1. 진단 완료 → **예상 점수 표시** → **8주 제안 화면**
  2. **결제 성공 시**에만 `program_status = active`, `current_week = 1` 설정
  3. 결제 전에는 "결제하고 8주 프로그램 시작" 유도

### 접근 제어
- `subscription_status != active`(또는 paid=false) 이면:
  - Week1 접근 불가
  - 결제 페이지(또는 설정)로 리다이렉트

## 5️⃣ 가격 필드 추가 (99,000 / 129,000)

### 목적
가격 A/B 테스트 및 할인 전략.

### 신규 테이블: pricing_plans
| 컬럼 | 타입 | 비고 |
|------|------|------|
| id | UUID | PK |
| plan_name | TEXT | 예: 8week_program |
| price | INT | 실제 가격 (원) |
| original_price | INT | 정가 (원) |
| currency | TEXT | KRW |
| is_active | BOOLEAN | 기본 true |
| created_at | TIMESTAMPTZ | |

### 기본 데이터
| plan_name | price | original_price |
|-----------|-------|----------------|
| 8week_program | 99000 | 129000 |

### 결제 성공 시 참조
- `subscriptions.plan_id` (선택) → `pricing_plans.id` 연결.
