# TOEAI 구간 리포트 설계 (베타 + 완성형 v2)

---

# 🎯 목적

구간 리포트는 단순 점수 표시가 아니라

> "학습 변화 + 개선 방향 + 다음 행동"

을 보여주는 핵심 기능이다.

---

# ⚠️ 베타 초기 핵심 전제 (중요)

- 베타 초기는 **데이터 시점이 1개뿐**이다.
- 따라서 **변화량(이전 vs 현재)** 계산이 불가능하다.

👉 설계 원칙:

- 1주차: 현재 상태 중심 리포트
- 2주차~: 변화 비교 리포트 활성화

---

# 1️⃣ 베타용 최소 리포트 (단계적 구현)

## 목표

- 2~3일 내 구현 가능
- 사용자에게 "효과"를 체감시키는 것
- DB 추가 없이 구현

---

## 📊 화면 구성 (조건 분기 포함)

### ✅ CASE 1: 데이터 1개 (초기 유저)

#### 1. 현재 예상 점수

- 현재 점수만 표시

예시:

- 현재 예상 점수: 870

---

#### 2. 현재 약점 TOP3

예시:

- 접속사 오류
- 어휘 부족
- Part7 추론 문제

---

#### 3. AI 코멘트 (rule 기반)

예시:

> 현재 가장 큰 약점은 접속사입니다. 해당 유형 집중이 필요합니다.

---

#### 4. 오늘/이번주 액션 3개

예시:

- Part5 하루 10문제
- 접속사 문제 집중 풀이
- Part7 2지문 시간 제한 풀이

---

### ✅ CASE 2: 데이터 2개 이상 (2주차~)

#### 1. 예상 점수 변화

- 시작 점수
- 현재 점수
- 변화량

예시:

- 시작: 850
- 현재: 880
- 변화: +30

---

#### 2. 약점 TOP3 변화

예시:

- 접속사 오류 ↓
- 어휘 문제 유지
- Part7 추론 개선 필요

---

#### 3. AI 코멘트 (rule 기반)

예시:

> 이번 구간에서는 Part7 시간 단축이 점수 상승에 영향을 주었습니다.

---

#### 4. 다음 구간 액션 3개

---

## 🧠 AI 코멘트 생성 로직 (베타)

- 가장 많이 틀린 태그 기준
- rule 기반 텍스트 생성

예:

- 접속사 → "접속사 집중 필요"
- 어휘 → "어휘 보강 필요"

---

## 🧱 데이터 소스

- tag_stats
- wrong_answers

👉 DB 추가 없음

---

## 💻 Cursor 1단계 명령어

```
구간 리포트 베타 버전 구현해줘.
기존 tag_stats와 wrong_answers 데이터만 활용하고 DB 추가 없이 구현.

화면 구성:
① 예상 점수 (시작/현재/변화량)
② 약점 TOP3 태그 변화 (이전 구간 대비)
③ AI 코멘트 1줄 (rule 기반, 가장 많이 틀린 태그 기준으로 자동 생성)
④ 다음 구간 액션 3개

단, 데이터가 1개 시점뿐일 경우엔
변화량 대신 '현재 약점'만 표시하도록 처리해줘.
```

# 2️⃣ 완성형 구간 리포트 (Paid)
