1. 실제 데이터 없는 섹션은 렌더하지 않는다

## 작업 4. 증거 섹션 — 조건부 렌더링

### 현재 문제
- `proof_assets` 쿼리는 이미 있으나 데이터 없어도 섹션 골격이 노출됨
- 빈 상태에서 "실사용자 변화" 섹션 틀만 보이는 것은 역효과

### 수정 규칙

```jsx
// 증거 섹션 전체를 아래 조건으로 감싼다
// proofList = proof_assets에서 is_public=true, review_stage=2 조회 결과

{proofList && proofList.length > 0 && (
  <section>
    {/* 증거 카드 최대 3개 노출 */}
    {proofList.slice(0, 3).map(...)}
  </section>
)}

// proofList가 없거나 length === 0이면 이 섹션 전체를 렌더하지 않는다
// 빈 div, 로딩 스피너, placeholder 일절 남기지 않는다
```

### 증거 카드 구조 (데이터 있을 때만)

```
카드 1장에 표시할 정보:
① 점수 변화:  815 → 870  (+55점)   ← 없으면 카드 미노출
② 사용 기간:  30일
③ 헤드라인:   proof_assets.headline 값
④ 후기 본문:  proof_assets.content 값 (최대 80자, 초과 시 말줄임)
```

### 증거 섹션 쿼리 (현재 쿼리를 이것으로 교체)

```js
const { data: proofList } = await supabase
  .from('proof_assets')
  .select('id, headline, content, start_score, current_score, usage_days')
  .eq('type', 'review')
  .eq('is_public', true)
  .eq('review_stage', 2)       // 전체 후기 작성 완료된 것만
  .order('created_at', { ascending: false })
  .limit(3)
```

## 작업 5. 플랜 카드 — 타겟 문구 추가

각 플랜 카드 상단에 타겟 문구 1줄 추가.
기존 플랜 설명은 유지하고 **앞에 한 줄 추가**만 하면 됨.

```
15일 플랜 카드 상단:  "시험 2주 이내 남은 사람"
30일 플랜 카드 상단:  "이번 시험 전 방향 잡고 싶은 사람"
60일 플랜 카드 상단:  "850 이상 정체 구간 탈출하고 싶은 사람"
```

플랜 네이밍:
```
15일: 시험 직전 압축
30일: 표준 점수 상승
60일: 정체 탈출 집중   ← "정체 탈출"로 반드시 변경
```
