# 토답 초대(Referral) 시스템 개발 명세서

## 0. 목적
토답의 초대 시스템은 신규 유입을 위한 광고 도구가 아니라  
**가치를 경험한 사용자가 자발적으로 추천하도록 만드는 구조**이다.

---

## 1. 핵심 원칙

1. 랜딩 페이지에서는 노출하지 않는다
2. 가치 경험 이후에만 노출한다
3. 결과 중심 메시지로 구성한다
4. 기간 연장 보상으로 설계한다

---

## 2. 노출 타이밍 (Trigger)

### 1차 노출 (필수)
- 조건:
  - 첫 오답 등록 완료
  - 첫 코칭 생성 완료

- 이벤트:
  - first_coaching_completed = true

---

### 2차 노출 (강화)
- 조건:
  - 결제 후 3일 경과
  - 최소 2회 이상 접속

- 이벤트:
  - day_3_active_user = true

---

### 3차 노출 (선택)
- 조건:
  - 구간 리포트 확인 완료

---

## 3. UI 위치

### 1. 코칭 완료 화면 하단
"오늘 할 일 생성 완료" 이후 노출

### 2. 마이페이지 (상시)
초대 코드 + 초대 현황 표시

### 3. 리포트 하단 (선택)

---

## 4. 카피 (문구)

### 기본
친구 초대하면 공부 기간이 늘어납니다

### 상세
- 친구 1명 초대 → +7일
- 3명 달성 → 추가 +21일

---

## 5. 데이터 구조 (Supabase)

### 테이블: referrals

- id (uuid)
- inviter_user_id (uuid)
- invite_code (text)
- invited_user_id (uuid)
- status (pending / completed)
- created_at (timestamp)

---

### 테이블: referral_rewards

- id (uuid)
- user_id (uuid)
- reward_days (int)
- reason (referral)
- created_at (timestamp)

---

## 6. 로직

### 초대 코드 생성
- 회원가입 시 자동 생성

### 초대 성공 조건
- 초대한 친구가 회원가입
- 첫 오답 등록 완료
- 첫 코칭 생성 완료

---

### 보상 지급 로직

if invited_user completes first_coaching:
    reward inviter +7 days

if inviter total referrals >= 3:
    additional +21 days

---

## 7. KPI

- 초대 클릭률
- 초대 → 가입 전환률
- 초대 → 결제 전환률
- 사용자당 평균 초대 수

---

## 8. Cursor 구현 지시문

토답 초대 시스템 구현:

1. 랜딩 페이지에서 초대 UI 제거
2. first_coaching_completed 시점에 초대 UI 노출
3. Supabase referrals, referral_rewards 테이블 생성
4. 사용자 가입 시 invite_code 자동 생성
5. 초대 성공 시 +7일 지급
6. 3명 달성 시 +21일 추가 지급
7. 마이페이지에 초대 코드 및 초대 수 표시
