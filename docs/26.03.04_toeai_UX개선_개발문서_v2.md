## 개선 1: 보기 (A/B/C/D) 내용 미표시

### 현상
- 분석 결과 화면에서 정답은 "B"로 표시되지만
- 보기 내용 (A. it / B. which / C. anyone / D. where)이 표시되지 않음
- 복습 시 "B가 뭐였지?" 확인 불가

### 수정 방법
AI 사진 분석 시 보기 A/B/C/D 내용도 함께 추출해서 저장 및 표시.

**분석 결과 화면 표시 형태:**
```
보기
A. it
B. which  ← 정답
C. anyone
D. where
```

**DB 저장 형태:**
```json
{
  "options": {
    "A": "it",
    "B": "which",
    "C": "anyone",
    "D": "where"
  },
  "answer": "B"
}
```

## 개선 2: 정답 입력란 개선

### 현상
- 정답 입력란에 "B" 알파벳만 입력/표시됨
- 복습 시 어떤 내용이 정답인지 바로 파악 어려움

### 수정 방법
정답 저장 및 표시를 "B. which" 형태로 변경.

보기가 추출된 경우 → 알파벳 선택 시 자동으로 내용 연결
보기 추출 실패한 경우 → 사용자가 직접 텍스트 입력 가능하게

**표시 형태:**
```
정답: B. which
```

## 개선 3: 빈칸 유형 / 문맥 태그 자동 선택 (가장 중요)

### 현상
현재 사용자가 수동으로 선택해야 하는 항목이 너무 많음:
- 빈칸 유형 (문장삽입 / 문법 / 어휘 / 연결어)
- 문맥 (앞문장미이해 / 전체흐름파악)
- 시간 부족 여부 체크박스
- 풀이 시간 입력
- 파트 선택
- 문제 텍스트 확인
- 정답 입력
- 해설 확인
- 태그 확인

→ 오답 1개 입력에 단계가 너무 많아 사용자 이탈 원인이 됨

### 수정 방법

**AI가 자동으로 선택하고, 사용자는 틀렸을 때만 수정하는 방식으로 변경**

```
변경 전: 사용자가 직접 선택
변경 후: AI 자동 선택 → 사용자는 확인/수정만
```

**구체적 변경사항:**

1. 빈칸 유형 → AI가 자동 분류 후 표시 (사용자는 수정만 가능)
2. 문맥 유형 → AI가 자동 분류 후 표시 (사용자는 수정만 가능)
3. 파트 → 문제 번호 기반 자동 결정 (수동 변경 가능)
4. 시간 부족 체크박스 → 선택사항 유지 (강제 아님)
5. 풀이 시간 → 선택사항 유지

**목표 UX 흐름:**
```
사진 찍기
→ AI 분석 (자동: 파트, 빈칸유형, 문맥, 보기, 정답 추출, 해설, 태그)
→ 사용자 확인 화면 (정답 필수 입력, 나머지는 AI 자동값 확인)
→ 저장
```

**최소 필수 입력값 (사용자가 반드시 해야 하는 것):**
- 정답 (A/B/C/D) → 필수
- 나머지는 모두 AI 자동값 → 선택적 수정
