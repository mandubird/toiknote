# OCR 이후 오답 선택 UX — Cursor AI 구현 지시문

## 핵심 목표
사진 업로드 → OCR 완료 후, 모든 문제를 순서대로 입력하던 방식을
**"틀린 문제만 체크 → 선택한 문제만 입력"** 방식으로 변경한다.

---

## 현재 코드 구조 (변경 전)

### Layout.jsx 흐름
```
handleUploadComplete(url)
  → analyzeToeicImage(url)           // Edge Function 호출
  → questions[] 반환                 // OCR 결과 배열
  → setAnalysisQueue(questions)      // 전체 문제 큐에 저장
  → setAnalysisResult(questions[0])  // 첫 번째 문제 세팅
  → setShowConfirmModal(true)        // 바로 입력 모달 열기  ← 여기를 바꾼다
```

### OCR 반환 데이터 구조 (question 1개)
```json
{
  "question_number": 147,
  "part": "Part 7",
  "lcOrRc": "RC",
  "question": "What is the purpose of the memo?",
  "answer": "",
  "options": { "A": "...", "B": "...", "C": "...", "D": "..." },
  "explanation": "...",
  "tags": ["추론", "목적"],
  "difficulty": 2,
  "passage_group_id": "pg_147_150"
}
```

### 관련 파일
- `src/components/Layout.jsx` — 상태 관리, 업로드 핸들러
- `src/components/AnalysisConfirmModal.jsx` — 문제 1개 상세 입력 모달 (변경 없음)

## 구현 범위

### 1. Layout.jsx 수정

**추가할 상태 2개:**
```jsx
const [showSelectionScreen, setShowSelectionScreen] = useState(false)
const [ocrAllQuestions, setOcrAllQuestions] = useState([])
```

**handleUploadComplete 수정:**
```jsx
// 기존 (삭제)
setAnalysisQueue(questions)
setCurrentQuestionIndex(0)
setAnalysisResult(questions[0])
setConfirmImageUrl(url)
setShowConfirmModal(true)

// 변경 후
setOcrAllQuestions(questions)
setConfirmImageUrl(url)
setShowSelectionScreen(true)
```

**OcrSelectionScreen 렌더링 추가 (AnalysisConfirmModal 바로 위에):**
```jsx
<OcrSelectionScreen
  open={showSelectionScreen}
  questions={ocrAllQuestions}
  wrongCount={wrongCount}  // 코칭 탭의 wrongCount와 같은 값 불필요 — 저장된 오답 수
  onConfirm={(selectedQuestions) => {
    setAnalysisQueue(selectedQuestions)
    setCurrentQuestionIndex(0)
    setAnalysisResult(selectedQuestions[0])
    setShowSelectionScreen(false)
    setShowConfirmModal(true)
  }}
  onClose={() => {
    setShowSelectionScreen(false)
    setOcrAllQuestions([])
    setConfirmImageUrl(null)
  }}
/>
```

**닫기/취소 시 초기화 (기존 onClose에 추가):**
```jsx
onClose={() => {
  setShowConfirmModal(false)
  setAnalysisResult(null)
  setConfirmImageUrl(null)
  setAnalysisQueue([])
  setCurrentQuestionIndex(0)
  // 추가
  setOcrAllQuestions([])
  setShowSelectionScreen(false)
}}
```

### 2. OcrSelectionScreen.jsx 신규 생성

**파일 위치:** `src/components/OcrSelectionScreen.jsx`

**Props:**
```
open: boolean
questions: array  // OCR 전체 결과
onConfirm: (selectedQuestions: array) => void
onClose: () => void
```

**내부 상태:**
```
checkedIndices: Set<number>  // 체크된 questions 배열 인덱스
```

**문제 요약 표시 규칙:**
- 표시 형식: `{question_number}. {question 앞 50자}…`
- question_number 없으면: `문제 {index+1}`
- question 텍스트 없으면: `(텍스트 없음)`
- Part 5/6: options.A ~ options.D 중 첫 번째 보기를 부제목으로 표시
- Part 7 / passage_group_id 있는 경우: 같은 passage_group_id끼리 시각적으로 묶음 표시 (얇은 구분선 + "지문 공유" 뱃지)

**UI 구조:**
```
[전체 화면 오버레이 — fixed inset-0 z-50 bg-white overflow-y-auto]

상단 헤더:
  문제를 분석했습니다. 틀린 문제만 선택해주세요.
  맞은 문제는 선택하지 않아도 됩니다.
  X 닫기 버튼 (오른쪽 상단)

요약 바:
  총 {questions.length}문제 인식 · 선택한 오답 {checkedIndices.size}개

문제 리스트 (스크롤):
  각 항목:
    [ 체크박스 ]  {question_number}. {question 앞 50자}…
                  {part} 뱃지
  체크 시 배경색 변경 (primary-50)

하단 고정 CTA:
  [선택한 문제만 입력하기]  → 최소 1개 선택 시 활성화
  비활성화 시: "틀린 문제를 1개 이상 선택해주세요" 문구
```

**전체 선택 / 전체 해제 버튼** 상단 우측에 추가 (선택 편의성)

## 저장 후 메시지 수정 (Layout.jsx)

기존 `alert('오답이 저장되었어요.')` 를 아래로 교체:

**마지막 문제 저장 후:**
```
오답 {저장된 총 개수}개가 기록되었어요.
```
→ 현재 `analysisQueue.length`로 계산 가능

**다음 문제로 이동 시:**
```
저장되었어요. 다음 문제 ({currentIndex+1}/{total}) 입력할게요.
```
→ `alert` 대신 가능하면 Toast UI 사용 (없으면 alert 유지)

## 설계 결정 사항 (Cursor가 임의로 바꾸지 말 것)

1. **선택 화면은 모달이 아닌 전체 화면 오버레이** — 문제가 많을 때 스크롤 공간 확보
2. **checkedIndices는 Set\<number\> (배열 인덱스 기준)** — question_number가 없는 케이스 대응
3. **기존 AnalysisConfirmModal은 그대로 사용** — multiTotal/multiIndex는 선택된 문제 수 기준으로 자동 적용됨
4. **passage_group_id 그룹핑은 시각적 묶음만** — 개별 체크는 각자 독립적으로 동작
5. **최소 1개 선택 조건** — 0개 선택 시 버튼 비활성화, onConfirm 호출 안 함
