Step 01
🛠️ 개발 도구 설치
1
터미널 열기
맥의 기본 앱이에요 — 명령어를 입력하는 검은 창
💡
터미널 여는 법: 키보드에서 Command ⌘ + Space 누르고 "터미널" 검색 → 엔터

검은 창이 하나 뜨면 성공이에요. 앞으로 모든 명령어는 여기에 붙여넣고 엔터를 누르면 됩니다.

2
Homebrew 설치
맥용 앱/도구 자동 설치 도우미예요

아래 명령어를 그대로 복사해서 터미널에 붙여넣고 엔터를 누르세요:

터미널에 붙여넣기
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
⚠️
중간에 비밀번호를 입력하라고 나와요. 맥 로그인 비밀번호를 입력하면 되는데, 입력해도 화면에 아무것도 안 보이는 게 정상이에요. 그냥 치고 엔터!
⏱️
설치에 2~5분 정도 걸려요. 뭔가 주르륵 흘러가면 잘 되고 있는 거예요.
3
Node.js 설치
React 앱을 실행하는 데 필요한 엔진이에요
터미널에 붙여넣기
brew install node
✅
설치 후 확인하려면: node --version 입력 → v20.x.x 같은 숫자가 뜨면 성공!
4
VS Code 설치
코드 편집기예요 — 파일 내용을 보고 수정할 때 씁니다
🌐
https://code.visualstudio.com 접속 → Download for Mac 클릭 → 다운로드된 파일 실행 → Applications 폴더에 드래그
Step 02
📁 프로젝트 파일 실행
1
프로젝트 압축 파일 받기 & 풀기
이 가이드와 함께 받은 toeai-app.zip 파일이에요
  1. 받은 toeai-app.zip 파일을 더블클릭해서 압축 해제
  2. 생성된 toeai-app 폴더를 바탕화면으로 이동
toeai-app/
  ├── src/ # 소스 코드
  │   ├── components/
  │   ├── pages/
  │   ├── App.jsx
  │   └── main.jsx
  ├── package.json # 의존성 목록
  ├── vite.config.js
  └── .env.local # ← 여기에 API 키 입력 (STEP 3)
2
터미널에서 폴더 열기
터미널이 "toeai-app 폴더 안"에 있도록 이동해요
터미널에 붙여넣기 (바탕화면에 폴더 있을 때)
cd ~/Desktop/toeai-app
💜
더 쉬운 방법: 터미널에 cd 입력 후 (스페이스 포함) → toeai-app 폴더를 터미널 창에 드래그 앤 드롭 → 엔터!
3
패키지 설치 & 앱 실행
필요한 라이브러리를 설치하고 앱을 켜요

① 먼저 패키지 설치 (최초 1회만)

터미널에 붙여넣기
npm install

② 앱 실행

터미널에 붙여넣기
npm run dev
🎉
터미널에 http://localhost:3000 이 뜨면 성공! 브라우저에서 해당 주소를 열면 토오AI가 보여요.
🛑
앱을 끄려면 터미널에서 Ctrl + C 누르면 돼요.
Step 03
🔑 API 키 설정 (중요!)
🔒
API 키는 절대 다른 사람과 공유하거나 공개 저장소에 올리지 마세요. 과금이 발생할 수 있어요.
!
.env.local 파일에 키 입력하기
toeai-app 폴더 안에 있는 .env.local 파일을 VS Code로 열어요

아래 항목들을 채워야 앱이 제대로 작동해요:

변수명 어디서 받나요?
VITE_FIREBASE_API_KEY Firebase 콘솔 → 프로젝트 설정 → 웹 앱 등록
VITE_FIREBASE_AUTH_DOMAIN Firebase 콘솔 → 웹 앱 config
VITE_FIREBASE_PROJECT_ID Firebase 콘솔 → 웹 앱 config
VITE_FIREBASE_STORAGE_BUCKET Firebase 콘솔 → 웹 앱 config
VITE_FIREBASE_MESSAGING_SENDER_ID Firebase 콘솔 → 웹 앱 config
VITE_FIREBASE_APP_ID Firebase 콘솔 → 웹 앱 config
VITE_OPENAI_API_KEY platform.openai.com → API Keys
📌
Firebase 처음 사용이라면? 아래 "Firebase 설정 가이드"를 따라해 주세요. console.firebase.google.com 접속 → 새 프로젝트 만들기 → Authentication, Firestore, Storage 각각 활성화
Step 04
🔥 Firebase 프로젝트 설정
1
Firebase 프로젝트 생성
console.firebase.google.com
  1. console.firebase.google.com 접속 → Google 로그인
  2. 프로젝트 만들기 클릭
  3. 프로젝트 이름: toeai-app 입력 → 계속
  4. Google Analytics: 비활성화 후 → 프로젝트 만들기
2
웹 앱 등록 및 config 복사
API 키를 가져오는 단계예요
  1. 프로젝트 홈에서 </> (웹) 아이콘 클릭
  2. 앱 닉네임: toeai-web 입력 → 앱 등록
  3. 화면에 나오는 firebaseConfig 내용을 복사 → .env.local에 붙여넣기
3
Authentication 설정
소셜 로그인 활성화
  1. 왼쪽 메뉴 → Authentication → 시작하기
  2. Sign-in method 탭 → Google 클릭 → 사용 설정 → 저장
💡
카카오 로그인은 별도 설정이 필요해요. 일단 Google 로그인만 먼저 해도 됩니다.
4
Firestore Database 생성
오답 데이터가 저장되는 곳
  1. 왼쪽 메뉴 → Firestore Database → 데이터베이스 만들기
  2. 테스트 모드로 시작 선택 → 다음
  3. 위치: asia-northeast3 (서울) 선택 → 완료
5
Storage 활성화
업로드한 사진이 저장되는 곳
  1. 왼쪽 메뉴 → Storage → 시작하기
  2. 테스트 모드로 시작 → 다음 → 완료
FAQ
🙋 자주 묻는 질문

Q. 터미널에서 에러가 났어요

에러 메시지를 그대로 Claude에게 붙여넣고 "이 에러 어떻게 해결해?" 라고 물어보세요. 대부분 바로 해결됩니다.

Q. npm install 이 너무 오래 걸려요

처음엔 1~3분 정도 걸릴 수 있어요. 기다려주세요!

Q. localhost:3000 이 안 열려요

npm run dev 를 다시 실행해보세요. 터미널이 toeai-app 폴더 안에 있는지도 확인해주세요.

Q. .env.local 파일이 안 보여요

파일 이름이 점(.)으로 시작하면 맥에서 숨김 처리돼요. VS Code에서 폴더를 열면 숨김 파일도 보입니다. 또는 터미널에서 ls -a 로 확인 가능해요.
