# 토답 전체 UI/UX 리디자인 — Cursor AI 개발 지시서

**작성일:** 2026-03-19
**버전:** v1.0
**목표:** "점수 향상 코칭 서비스"의 긴장감·신뢰감·집중도를 전체 화면에 구현
Generic 파란색 SaaS 템플릿 → **토답만의 브랜드 감**으로 전환

---

## 배경 및 문제 정의

현재 화면의 5가지 구조적 문제:

1. **영역 분리 없음** — 로고/콘텐츠/하단 메뉴가 전부 연한 회색/흰색 톤, 층이 안 생김
2. **핵심 행동이 늦게 보임** — 지금 모드·이유·할 일·CTA가 시각적으로 묻혀 있음
3. **카드 중요도 미분화** — 모든 카드가 비슷한 스타일이라 우선순위 전달 안 됨
4. **CTA 맥락 약함** — "전략 분석 시작" 버튼이 위 맥락 없이 덩그러니 있음
5. **브랜드 감 없음** — 토답의 "점수 향상 긴장감"이 화면에서 안 느껴짐

---

## 1단계: 컬러 시스템 교체 (`tailwind.config.js`)

현재 `primary`(일반 파란색)를 아래로 **전체 교체**한다.

```js
// tailwind.config.js → theme.extend.colors 전체 교체
colors: {
  // 브랜드 네이비 — 신뢰·권위·학습 연상
  primary: {
    50:  '#eef2ff',
    100: '#e0e7ff',
    200: '#c7d2fe',
    300: '#a5b4fc',
    500: '#4f46e5',
    600: '#4338ca',   // 주요 CTA, 활성 탭
    700: '#3730a3',   // hover
    900: '#1e1b4b',   // 헤더 배경
  },
  // 긴장감 오렌지 — 행동 유도, D-day, 약점 강조
  accent: {
    50:  '#fff7ed',
    100: '#ffedd5',
    400: '#fb923c',
    500: '#f97316',   // 핵심 CTA, 긴급 표시
    600: '#ea580c',
    700: '#c2410c',
  },
  // 점수 그린 — 성취, 상승 표시
  score: {
    50:  '#f0fdf4',
    500: '#22c55e',
    600: '#16a34a',
    700: '#15803d',
  },
  // 중립 배경 (cold gray → warm slate)
  surface: {
    50:  '#f8fafc',
    100: '#f1f5f9',
    200: '#e2e8f0',
    400: '#94a3b8',
    600: '#475569',
    900: '#0f172a',
  },
},
```

**심리적 근거:**
- 네이비(`#4338ca`): 수험·코칭 시장에서 신뢰·전문성 연상. 기존 파란색보다 무게감 있음
- 오렌지(`#f97316`): "지금 해야 한다"는 긴박감 자극. D-day·약점·CTA에 사용
- 그린: 점수 상승·달성감. 숫자 옆에만 제한 사용
- `bg-white` 카드 배경 → `bg-surface-50` 으로 통일 (warm gray)

## 주의사항

1. **로직 건드리지 말 것** — state, API 호출, navigate, 조건부 렌더링 로직 유지
2. **`safe-area-top`, `safe-area-bottom`** 클래스 반드시 유지 (iOS 노치 대응)
3. **`primary-*` 클래스명은 그대로 유지** — `tailwind.config.js`에서 색상 값만 교체되므로 기존 className은 자동 반영됨. `accent-*`, `score-*`, `surface-*`는 새로 추가된 토큰이므로 사용 가능
4. **애니메이션 유지** — `animate-spin`, `animate-pulse-slow` 등 기존 애니메이션 제거 금지
5. **모달/오버레이 컴포넌트** (`PaywallModal`, `OnboardingModal`, `AnalysisConfirmModal`) — 이번 작업 범위 밖. 건드리지 말 것
