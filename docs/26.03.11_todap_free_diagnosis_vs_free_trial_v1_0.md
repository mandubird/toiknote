# [토답] "무료 진단"과 "오답 5문제 무료 체험" 분리 및 별도 진단 플로우 설계 문서 v1.0

문서 목적:
현재 토답 랜딩페이지의 핵심 CTA인 **"무료 진단"**과,
실제 앱 내부 무료 기능인 **"오답 5문제 무료 체험"**이 서로 혼용되어 사용자에게 혼란을 줄 수 있는 문제를 해결하기 위해,
두 기능의 역할을 명확히 분리하고, 별도의 무료 진단 플로우를 설계한다.

이 문서는 아래 3가지를 명확히 정의한다.

1. 무료 진단과 무료 체험의 차이
2. 별도 무료 진단 플로우의 목적과 단계
3. 결과 화면 이후 오답 5문제 체험으로 자연스럽게 연결되는 구조

---

# 1. 핵심 결론

결론부터 정리하면 다음과 같다.

- **"무료 진단"**과 **"오답 5문제 무료 체험"**은 같은 기능이 아니다.
- 둘은 반드시 분리되어야 한다.
- 무료 진단은 **가입 직후 빠르게 방향을 잡아주는 사전 평가**이고,
- 오답 5문제 무료 체험은 **실제 앱 기능을 써보며 진단 정확도를 높이는 제품 체험**이다.

즉, 두 기능은 아래처럼 정의한다.

## 무료 진단
- 사진 없이도 시작 가능
- 점수, 시험일, 체감 약점, 공부 방식 등을 입력받아
- 현재 예상 점수, 점수 손실 원인, 전략 모드를 먼저 보여주는 기능

## 오답 5문제 무료 체험
- 사용자가 실제 문제를 등록
- 오답 태그, 파트, LC 원인, 약점 체크리스트 등을 정밀 보정
- 진단 결과를 더 정확하게 만드는 기능

---

# 2. 왜 분리해야 하는가

현재 랜딩에서는 사용자에게 아래 같은 메시지를 전달하고 있다.

- 현재 예상 점수
- 점수 손실 원인 Top 3
- 시험일까지 압축 전략
- 무료 점수 진단 받기

하지만 실제 앱 첫 경험이
"오답 5문제 체험"
이라면, 사용자는 아래처럼 느낄 수 있다.

> 랜딩에서는 진단해준다고 했는데, 앱 들어오니 문제부터 찍으라고 하네?

이건 랜딩 메시지와 앱 첫 경험이 어긋나는 상태다.

따라서 아래처럼 구조를 재정렬해야 한다.

```text
랜딩 CTA → 무료 진단 → 결과 확인 → 오답 5문제 무료 체험 → 정밀 보정
```

즉,

- 무료 진단은 **방향 잡기**
- 무료 체험은 **정밀도 올리기**

이렇게 역할이 달라야 한다.

# 3. 무료 진단과 무료 체험의 차이 정의

## 3.1 무료 진단의 정의

무료 진단은 토답에 처음 들어온 사용자가
사진 업로드 없이도 빠르게 자신의 현재 상태를 파악할 수 있도록 하는 사전 평가 기능이다.

### 무료 진단이 주는 것
- 현재 예상 점수
- 목표까지 필요한 점수
- 가장 큰 손실 원인 Top 3
- 현재 전략 모드
- 첫 번째 추천 액션

### 무료 진단의 핵심 가치
- 지금 내 점수가 왜 안 오르는지 감을 잡게 한다
- 무엇부터 공부해야 하는지 우선순위를 보여준다
- 시험일까지 남은 기간에 따라 전략이 달라진다는 점을 체감하게 한다

---

## 3.2 오답 5문제 무료 체험의 정의

오답 5문제 무료 체험은
사용자가 실제 문제를 등록해
토답의 핵심 기능을 써보는 제품 체험 기능이다.

### 오답 5문제 체험이 주는 것
- 파트 자동 분류
- 태그 자동 분류
- keyVocabulary 추출
- LC 수동 원인 선택
- 약점 체크리스트 보정
- AI 코치 정확도 향상

### 무료 체험의 핵심 가치
- 무료 진단 결과를 더 정확하게 만든다
- 단순 설문 진단이 아닌 실제 오답 기반 분석으로 이어진다
- 사용자가 토답의 기능적 차별점을 경험하게 한다

---

## 3.3 한 줄 정의

### 무료 진단
가입 직후 제공되는 **사전 평가**

### 오답 5문제 무료 체험
제품 기능을 직접 써보는 **정밀 보정 체험**

---

# 4. 전체 사용자 흐름 재설계

최종 흐름은 아래처럼 설계한다.

```text
랜딩 CTA 클릭
→ 회원가입 / 로그인
→ 무료 진단 시작
→ 현재 점수 / 손실 원인 / 전략 결과 확인
→ "오답 5문제로 진단 정확도 높이기" 제안
→ 오답 5문제 무료 체험
→ 체크리스트/전략/대시보드 연결
```

핵심은:
사용자가 기능을 먼저 배우는 게 아니라,
**결과를 먼저 보고**
그 결과를 더 정밀하게 만들기 위해 체험을 이어가게 해야 한다.

# 5. 별도 무료 진단 플로우 설계

---

# 5.1 무료 진단의 목표

무료 진단은 사진 업로드 없이도 아래를 먼저 보여주는 것을 목표로 한다.

1. 현재 예상 점수
2. 목표까지 필요한 점수
3. 가장 큰 점수 손실 원인 Top 3
4. 시험일까지의 전략 모드
5. 지금 가장 먼저 해야 할 것

즉, 토답의 핵심 가치를 미리 체험하게 한다.

---

# 5.2 무료 진단 단계 구조

## Step 0. 진단 시작 화면

### 목적
사용자에게 무료 진단이 무엇인지 간단히 이해시키고 시작하게 한다.

### 제목
무료 점수 진단

### 설명
최근 점수와 시험일까지 남은 시간을 바탕으로  
현재 예상 점수와 핵심 약점을 먼저 진단해드립니다.

### 버튼
진단 시작하기

### 주의사항
- 여기서는 오답 사진 업로드를 먼저 요구하지 않는다
- "5문제 등록" 문구를 노출하지 않는다
- 가입 직후 첫 온보딩 화면으로도 사용할 수 있다

---

## Step 1. 최근 점수 입력

### 목적
현재 점수 상태의 큰 방향을 잡기 위한 입력 단계

### 질문
최근 TOEIC 점수를 입력해주세요

### 입력 항목
- 총점
- LC 점수
- RC 점수

### UI 가이드
- 총점, LC, RC를 각각 입력
- 최근 실제 시험 기준을 우선
- 실제 시험이 없으면 모의고사 기준도 허용

### 예외 처리
최근 점수를 정확히 모를 경우 아래 선택지 제공

#### 대략 점수대 선택
- 600 미만
- 600~699
- 700~799
- 800~899
- 900+

### 시스템 처리
입력값을 기반으로:
- current_score
- lc_score
- rc_score
- score_band
계산 또는 저장

---

## Step 2. 목표 점수 / 시험일 입력

### 목적
목표와 일정 기반 압축 전략 계산

### 질문
목표 점수와 시험일을 알려주세요

### 입력 항목
- 목표 점수
- 시험일

### 계산 항목
- score_gap = target_score - current_score
- d_day = exam_date - today

### 활용 목적
- 압축 전략 모드 계산
- 전략 카드 구성
- CTA 개인화

---

## Step 3. 체감 약점 선택

### 목적
사용자가 스스로 느끼는 약점을 반영해
초기 진단의 정확도를 높인다.

### 질문
어디서 가장 점수를 잃고 있다고 느끼시나요?

### 복수 선택 항목
- Part 5 문법
- Part 5 어휘
- Part 2 우회답변
- LC 집중력/발음
- Part 7 시간 부족
- Part 7 추론/패러프레이즈
- 아직 잘 모르겠어요

### 추가 분기 질문 예시

#### Part 7 선택 시
- 항상 5~10문제 못 풀고 끝난다
- 시간은 맞지만 정확도가 낮다
- 복수지문이 특히 어렵다

#### LC 선택 시
- 들었는데 답을 못 고르겠다
- 우회답변이 어렵다
- 비슷한 발음에 자주 속는다

#### Part 5 선택 시
- 문법이 약하다
- 어휘가 약하다
- 둘 다 애매하다

### 목적
- self_reported_weaknesses 저장
- weakness_top_3 추정 정확도 향상
- 코치 메시지 개인화

---

## Step 4. 공부 패턴 선택

### 목적
현재 사용자의 공부 방식 자체에서 문제가 있는지 파악하고,
잘못된 방법 vs 올바른 방법 결과와 연결한다.

### 질문
현재 공부 방식과 가장 가까운 것을 골라주세요

### 단일 선택 항목
- 문제만 많이 풀고 있다
- 약점은 아는데 정리가 안 된다
- 오답 정리는 하지만 반복된다
- 시험일까지 계획이 없다
- 실전에서 시간 관리가 무너진다

### 활용 목적
- study_pattern 저장
- 결과 화면의 코치 문구 개인화
- 향후 추천 루틴 생성

---

## Step 5. 진단 결과 출력

### 목적
사용자가 “아, 이 서비스는 내 상황을 바로 정리해주는구나”를 느끼게 하는 핵심 화면

### 출력 항목
1. 현재 예상 점수
2. 목표까지 필요한 점수
3. 가장 큰 손실 원인 Top 3
4. 현재 전략 모드
5. 첫 번째 추천 액션

### 결과 화면 예시

#### 제목
진단 결과

#### 카드 1
현재 예상 점수  
**650점**

#### 카드 2
목표까지  
**+250점**

#### 카드 3
가장 큰 손실 원인
- Part 5 기초 문법
- Part 7 시간 관리
- Part 2 우회답변

#### 카드 4
현재 전략 모드  
**D-23 고압축 모드**

#### 카드 5
지금 가장 먼저 해야 할 것  
**Part 7보다 Part 5 기초 문법을 먼저 줄이는 것이 더 효율적입니다.**

# 7. 결과 화면 이후 무료 체험 연결 구조

무료 진단은 “방향 잡기”이고,
오답 5문제 무료 체험은 “정밀도 올리기”다.

따라서 결과 화면 이후 무료 체험 흐름은 아래처럼 안내한다.

```text
진단 결과 확인
→ 오답 5문제 무료 체험 시작
→ 태그 분석 / 파트 분류 / LC 원인 선택
→ 체크리스트 상태 보정
→ 대시보드/전략/약점 화면 반영
```

이 구조가 맞다.
