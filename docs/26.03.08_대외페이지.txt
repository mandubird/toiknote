4-2. 질문 목록
Q1. 토오AI는 어떤 서비스인가요?

토오AI는 사용자의 오답 문제와 학습 데이터를 기반으로
예상 점수, 약점 영역, 학습 전략을 제안하는 교육용 소프트웨어입니다.
실시간 강의나 1:1 과외/교습 서비스는 제공하지 않습니다.

Q2. 100일 프로그램은 무엇인가요?

결제일 기준 최대 100일 동안 사용할 수 있는 디지털 프로그램입니다.
시험일을 입력하면 남은 기간에 맞춰 전략이 압축될 수 있습니다.

Q3. 토오AI는 학원인가요?

아닙니다.
토오AI는 사용자가 직접 학습에 활용하는 교육용 소프트웨어/디지털 콘텐츠 서비스입니다.

Q4. 결제 후 바로 이용할 수 있나요?

네. 결제 완료 후 즉시 이용 가능합니다.

Q5. 환불은 어떻게 되나요?
→ 환불 규정 페이지 링크 연결
Q6. 시험일은 변경할 수 있나요?

가능합니다. 설정에서 시험일을 변경하면 전략이 다시 계산됩니다.

Q7. LC 오답 원인은 어떻게 분석하나요?

LC는 오디오 기반 특성상 일부 원인은 AI가 직접 파악하기 어렵기 때문에,
사용자가 오답 원인을 선택하면 이를 기반으로 분석이 진행됩니다.

4. 단순 변심 환불 요청의 경우에도,
