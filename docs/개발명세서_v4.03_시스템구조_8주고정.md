---

## 0. 시스템 상위 구조 정의 (필수)

### 🎯 Program Architecture

```
Program = 8 Weeks

Stage 1: 진단 (Week 0)
Stage 2: 약점 교정 (Week 1~6)
Stage 3: 실전 최적화 (Week 7~8)
```

### 📌 Global Rule

| 규칙 | 설명 |
|------|------|
| 진단 완료 전 | Week1 접근 불가 |
| Week 순차 진행 | N주 완료 전에는 N+1주 미개방 |
| 점수 예측 노출 | Week4 이후부터만 노출 |
| 주간 PDF 생성 | Week1 이상 사용자만 생성 가능 (Pro 전용) |

---

## 🔥 A. Feature Priority

| 순위 | 항목 | 비고 |
|------|------|------|
| 1순위 | 진단 화면 + 진단 DB | diagnostic_results, 진단 완료 시 Week1 해제 |
| 2순위 | Week 진행 로직 | 순차 진행, completion ≥ 70% → next_week_unlock |
| 3순위 | 주간 PDF | Pro 전용, week 종료 시 조건 만족하면 생성 |
| 4순위 | 점수 예측 | Week4+ 노출, Pro 전용 |
| 5순위 | AI 코치 멘트 고도화 | 4줄 형식 고정 |

---

## 🔥 B. 접근 제어 룰

| 대상 | 무료 | Pro |
|------|------|-----|
| Week 진행 | Week2까지 | Week8까지 |
| 주간 PDF | 불가 | 가능 |
| 점수 예측 | 불가 | 가능 (Week4+) |
| 진단 | 가능 (1회 이상) | 동일 |

- **진단 완료 전**: 프로그램 탭에서 Week1~8 모두 비활성, "진단 먼저 하기" 유도.
- **Pro**: `subscriptions.paid === true` (또는 plan pro/elite).

---

## 🔥 C. 상태 전이 로직

```
[진단 미완료] → 프로그램 진입 시 진단 페이지로 유도

diagnostic_completed → week1_unlocked
  (diagnostic_results 1건 이상 존재 시 current_week 1 접근 허용)

week_completion ≥ 70% → next_week_unlock
  (해당 주 completion_rate ≥ 70% 시 다음 주로 진행 버튼 활성화)

week8_complete → final_report_generate
  (8주 완료 시 최종 리포트 생성 가능, Pro만 PDF)
```

## ✅ 1. [Stage 1] 진단 (Week 0)

### 📌 1.1 목적
- 사용자의 현재 점수 및 파트별 약점 수치화
- 진단 완료 시에만 Week1 접근 허용

### 📌 1.2 DB 정의

**table: diagnostic_results**

| 컬럼 | 타입 | 비고 |
|------|------|------|
| id | UUID | PK |
| user_id | UUID | FK auth.users |
| rc_score | INT | 0~495 |
| lc_score | INT | 0~495 |
| part5_score | INT | RC 내 Part5 추정 |
| part6_score | INT | RC 내 Part6 추정 |
| part7_score | INT | RC 내 Part7 추정 |
| overall_score | INT | rc_score + lc_score |
| weakest_part | INT | 5 or 6 or 7 (MIN 점수 파트) |
| created_at | TIMESTAMPTZ | |

- 진단 2회 이상 시 → **최신 1건** 기준으로 진단 완료 여부·점수 사용.

### 📌 1.3 계산 로직
- `overall_score = rc_score + lc_score`
- `weakest_part = part5/6/7 중 점수 최소인 파트 번호`
- rc/lc/part5/6/7 점수: 기존 tag_stats·wrong_answers 기반 추정 또는 사용자 입력값 저장.

### 📌 1.4 API
- `POST / 진단 완료`: 진단 결과 저장 (diagnostic_results insert), users.diagnostic_completed_at 갱신(또는 diagnostic_results 존재로 완료 판단).
- `GET / 진단 결과`: 해당 user_id 최신 diagnostic_results 1건 반환.

### 📌 1.5 UX
- 진단 완료 시:
  - 약점 그래프 표시 (Radar 또는 Bar: part5/6/7, lc/rc)
  - **"Week1 시작하기"** 버튼 활성화
- 진단 미완료 시 프로그램 메인에서 "진단 먼저 하기" 노출.

### 📌 1.6 예외 처리
- 진단 데이터 없으면 프로그램 Week1~8 접근 불가 (버튼 비활성 또는 리다이렉트).
- 진단 2회 이상 시 → 최신값 기준.

## ✅ 2. [Stage 2] 약점 교정 (Week 1~6)

### 📌 2.1 목적
- 약점 파트 집중 개선
- **Week 구조 고정** (동적 변경 없음)

### 📌 2.2 Week 구조 (고정)

| 주차 | 목표 |
|------|------|
| Week 1~2 | RC 집중 (Part 5, 6, 7) |
| Week 3~4 | Part7 집중 (시간·정확도) |
| Week 5~6 | LC 집중 (Part 1~4) |

- 개발 시 위 구조를 템플릿/코드에 고정. 사용자별로 주차 순서 바꾸지 않음.

### 📌 2.3 table: weekly_progress (또는 기존 테이블 확장)

| 컬럼 | 타입 | 비고 |
|------|------|------|
| id | UUID | PK |
| user_id | UUID | |
| week_number | INT | 1~8 |
| target_part | INT[] or TEXT | 해당 주 집중 파트 |
| completion_rate | NUMERIC | 0~100, 주차 완료율 |
| accuracy_rate | NUMERIC | 해당 주 정확도 |
| ai_feedback | TEXT | AI 코치 멘트 (4줄 형식) |
| created_at, updated_at | TIMESTAMPTZ | |

- 기존 `user_program_plans` + `weekly_reports`와 매핑 가능. completion_rate·accuracy_rate·ai_feedback 필드 확장 또는 weekly_progress 신규 생성.

### 📌 2.4 AI 코치 멘트 규칙 (형식 고정)

반드시 아래 4줄 구조:

```
[1] 현재 정확도: OO%
[2] 전주 대비 변화: +OO% / -OO%
[3] 이번 주 집중 포인트 1문장
[4] 다음 주 전략 1문장
```

- API/저장 시 4줄 한 덩어리로 저장하거나, 4필드로 저장 후 조합 표시.

### 📌 2.5 주간 PDF 생성 로직

- **조건**
  - 해당 주 `completion_rate ≥ 70%`
  - 해당 주 종료 시점에 생성
  - **Pro 전용** (무료 사용자 PDF 생성 불가)
- **PDF 포함 내용**
  - 점수 변화 그래프
  - 파트별 정확도
  - AI 코치 종합 멘트 (위 4줄 형식)
- 서버(또는 Edge Function)에서 생성.

## ✅ 3. [Stage 3] 실전 최적화 (Week 7~8)

### 📌 3.1 목적
- 점수 예측 + 실전 시뮬레이션

### 📌 3.2 table: score_prediction

| 컬럼 | 타입 | 비고 |
|------|------|------|
| user_id | UUID | PK 또는 UNIQUE |
| predicted_score | INT | 0~990 |
| confidence_rate | NUMERIC | 0~100 |
| updated_at | TIMESTAMPTZ | |

### 📌 3.3 예측 계산 로직
- 최근 3주 평균 정확도
- \+ 약점 개선 추세 가중치
- \= 예측 점수 (구간 또는 단일값)

### 📌 3.4 노출 조건
- **Week4 이상** 사용자에게만 점수 예측 노출
- 최소 학습 데이터 200문제 이상 (선택: total solved ≥ 200)
- **Pro 전용** 노출

### 📌 3.5 Week 7~8 UX
- Week 7: 실전 시뮬레이션 (시간 제한 모드 등)
- Week 8: 점수 예측 범위 + 최종 전략 + PDF(Pro)
