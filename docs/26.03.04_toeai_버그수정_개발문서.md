## 🐛 버그 1호: LC 문제를 Part 7(RC)로 잘못 분류

### 문제 현상
- 사용자가 토익 LC 파트(Part 1~4) 문제 사진을 찍으면
- AI가 텍스트만 보고 Part 7 단일지문으로 잘못 분류함
- 예: 66번 문제(Part 3 대화)를 "Part 7: 단일지문"으로 분류

### 원인
- AI가 문제 번호를 무시하고 텍스트 내용만으로 파트를 판단함
- 토익 LC는 음성 기반이라 텍스트만으로 구분 불가

### 토익 파트별 문제 번호 범위 (기준)
```
Part 1: 1~6번
Part 2: 7~31번
Part 3: 32~70번
Part 4: 71~100번
Part 5: 101~130번
Part 6: 131~146번
Part 7: 147~200번
```

### 수정 방법

**방법 A: 문제 번호 기반 자동 분류 (권장)**

AI 이미지 분석 프롬프트에 아래 로직 추가:

```
1. 이미지에서 문제 번호(숫자)를 먼저 추출한다
2. 문제 번호 범위로 파트를 판단한다:
   - 1~6번 → Part 1 (LC)
   - 7~31번 → Part 2 (LC)
   - 32~70번 → Part 3 (LC)
   - 71~100번 → Part 4 (LC)
   - 101~130번 → Part 5 (RC)
   - 131~146번 → Part 6 (RC)
   - 147~200번 → Part 7 (RC)
3. 문제 번호가 감지되지 않을 경우에만 텍스트 내용으로 판단
```

**방법 B: 사용자 수동 선택 UI 추가 (단기 대응)**

오답 저장 시 "1단계: 분석 결과 확인" 모달에서:
- 파트 선택 드롭다운 추가 (Part 1 ~ Part 7)
- AI 분류 결과를 기본값으로 표시
- 사용자가 틀렸을 경우 수정 가능하게

> **권장: 방법 A + B 동시 적용**
> A로 정확도 높이고, B로 사용자가 직접 수정 가능하게

## 🐛 버그 2호: 한 사진에서 첫 번째 문제만 인식, 나머지 누락

### 문제 현상
- 토익 Part 7은 지문 1개에 문제 2~5개가 세트로 구성됨
- 사용자가 한 페이지(147번+148번) 사진을 찍으면
- 앱이 147번만 저장하고 148번은 누락

### 영향
- Part 7 복수지문 문제는 2~5개가 한 세트
- 현재 구조로는 세트 전체를 오답 처리 불가
- 실제 토익 학습 패턴과 불일치 → 유저 이탈 원인

### 토익 Part 7 구조
```
단일지문(Single Passage): 지문 1개 + 문제 2~3개
복수지문(Multiple Passage): 지문 2~3개 + 문제 4~5개
```

### 수정 방법

**AI 프롬프트 수정:**

```
이미지에서 문제를 분석할 때:
1. 이미지 내 모든 문제 번호를 탐지한다
2. 문제가 여러 개인 경우 각각 별도의 오답 객체로 반환한다
3. 같은 지문을 공유하는 문제들은 "passage_group_id"로 묶어서 반환한다

반환 형식 (복수 문제인 경우):
{
  "questions": [
    {
      "question_number": 147,
      "part": 7,
      "question_text": "...",
      "options": {...},
      "answer": "C",
      "explanation": "...",
      "tags": [...],
      "passage_group_id": "pg_147_148"
    },
    {
      "question_number": 148,
      "part": 7,
      "question_text": "...",
      "options": {...},
      "answer": "C",
      "explanation": "...",
      "tags": [...],
      "passage_group_id": "pg_147_148"
    }
  ]
}
```

**프론트엔드 수정:**

1단계 분석 결과 모달을 복수 문제 지원으로 수정:
- 단일 문제 → 기존 UI 유지
- 복수 문제 감지 시 → "이 지문에서 N개 문제가 발견됐어요" 안내
- 각 문제별로 저장/취소 선택 가능하게
- 전체 저장 버튼 추가 ("N개 모두 저장")

**DB 수정:**

wrong_answers 테이블에 컬럼 추가:
```sql
ALTER TABLE wrong_answers 
ADD COLUMN passage_group_id VARCHAR(50) DEFAULT NULL;
-- 같은 지문 문제들을 그룹으로 묶기 위한 컬럼
```

## 테스트 시나리오 (수정 후 검증용)

- [ ] Part 3 문제(32~70번) 사진 → Part 3으로 분류되는지 확인
- [ ] Part 4 문제(71~100번) 사진 → Part 4로 분류되는지 확인
- [ ] Part 7 문제(147번~) 사진 → Part 7로 분류되는지 확인

- [ ] Part 7 복수지문 페이지(4~5문제) 사진 → 전체 저장 가능한지 확인
