## 1. 수익화 상품 구조

### 상품 라인업

| 플랜 | 기간 | 가격 | 포지셔닝 |
|------|------|------|----------|
| 파이널 압축 | 15일 | 29,900원 | 시험 2주 전 응급 전략 |
| 표준 코칭 | 30일 | 49,900원 | 기본 루틴 + 전략 |
| 정체 탈출 | 60일 | 79,900원 | 장기 교정 |

### 핵심 철학

```
기간 ❌
상황 ⭕
```

→ 유저는 "30일짜리"를 사는 게 아니라 **"지금 이 상황을 해결"**하는 것을 산다.

### 결제 후 즉시 제공 (온보딩)

결제 완료 즉시 다음 세 가지를 화면에 노출:

- **약점 TOP3** — 오답 데이터 기반 자동 추출
- **오늘 할 일 3개** — 우선순위 코칭 리스트
- **버려야 할 것 1개** — 지금 당장 손놓을 항목

### 수익 구조 방향

```
MRR ❌
→ 신규 유입 + 후기 ⭕
```

반복 구독이 아닌, 목표 달성 → 후기 생성 → 신규 전환 루프로 성장.

## 2. KPI 개발 명세

### 핵심 전환

```
구독 KPI ❌
→ 목표 달성형 KPI ⭕
```

```
Retention ❌
→ Activation + Outcome + Proof ⭕
```

### 핵심 KPI 5가지

1. **고의도 유입** — 시험 D-14~D-30 구간 유저 비율
2. **첫날 활성화율** — 결제 후 24시간 내 온보딩 완료율
3. **7일 사용률** — 7일 내 코칭 3회 이상 진입 비율
4. **목표 달성 체감** — self-report 기반 (베타 피드백 폼)
5. **후기/추천 발생률** — proof_assets 생성 수 / 결제 수

### 활성화 정의 (24h 기준)

결제 후 24시간 내 아래 세 가지 완료 시 "활성화" 처리:

- [ ] 약점 TOP3 확인
- [ ] 오늘 할 일 3개 확인
- [ ] 오답 1개 이상 등록

### 7일 사용률 기준

- 7일 내 코칭 진입 **3회 이상** = 사용자로 카운트

### 후기 발생률 산식

```
후기 발생률 = proof_assets 생성 수 / 결제 수
```

## 3. 베타 모집 + 전환 전략

### 핵심 메시지

> **"이번 시험 전 점수 올리고 싶은 사람만"**

### 모집 카피

> 시험 전 2~4주 남았나요?
>
> 지금 뭘 해야 할지 모르겠다면
> 토답이 **"버릴 것 + 할 것"** 바로 정해드립니다.
>
> 무료 베타 5명

### 전환 포인트

```
기능 설명 ❌
"지금 상황 해결" ⭕
```

### DM 스크립트

**첫 질문 2개:**
1. "시험 언제인가요?"
2. "어디에서 막히세요?"

**결제 유도 멘트:**
> "지금 상황이면 **15일 압축 플랜**이 맞아요"

## 4. 베타 운영 가이드

### 목적

> 첫 결제 + 첫 결과 경험

### 운영 도구 구조

| 도구 | 용도 |
|------|------|
| Form | 피드백 수집 |
| Notion | 유저별 인사이트 정리 |
| DM | 깊은 인사이트 수집 |

### 베타 유저 포지셔닝

```
베타 유저 = 데이터 + 증거 생성자
```

### 추가 KPI (베타 한정)

- 첫날 코칭 확인 여부
- 오늘 할 일 실행 여부

### 필수 피드백 질문

1. "오늘 할 일 해봤나요?"
2. "방향이 명확해졌나요?"

## 5. 관리자 시스템

### KPI 대시보드

| 지표 | 기준 |
|------|------|
| Activation | 결제 후 24h 내 온보딩 완료 |
| 7일 사용률 | 7일 내 코칭 3회 이상 |
| 후기 생성 수 | proof_assets 생성 건수 |
| 추천 발생 수 | 레퍼럴 코드 or DM 경로 추적 |

### 유저 리스트 필터

- 결제 후 미활성 (24h 초과)
- 3일 미사용
- 후기 없음

### DM 전략 3단계

| 단계 | 내용 | 발송 타이밍 |
|------|------|-------------|
| 1차 | 활성화 유도 | 결제 후 D+1 |
| 2차 | 실행 유도 | D+3 미사용 시 |
| 3차 | 후기 요청 | D+7 이후 |

### 증거(Proof) 시스템

```
proof_assets → 랜딩 자동 노출
```

**수집 타입:**

| 타입 | 설명 |
|------|------|
| 후기 | 텍스트 or 캡처 |
| 전후 비교 | 점수 변화 스크린샷 |
| 인사이트 | 유저가 발견한 패턴 |

**운영 루프:**

```
데이터 → 행동 → 증거 → 전환
```
